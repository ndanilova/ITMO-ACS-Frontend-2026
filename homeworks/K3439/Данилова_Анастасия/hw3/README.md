# ДЗ3 — CSS-переменные, темизация сайта

Данилова Анастасия, K3439. Сайт Snimu (вариант 4, аренда недвижимости) — версия после ЛР2 и ДЗ2.

## Задание

Добавить к сайту дополнительную тему: либо светлая и тёмная с ориентиром на настройки пользователя,
либо две кастомные темы с переключателем на JS.

Сделаны оба варианта сразу: тёмная тема включается сама по системной настройке,
и её можно переключить вручную кнопкой в шапке.

## Что сделано

**1. Цвета вынесены в CSS-переменные** (`css/style.css`)

Все цвета, которые раньше были прописаны прямо в правилах, собраны в `:root`:

```css
:root {
  --bg: #f5f6f8;
  --surface: #ffffff;
  --text: #212529;
  --border: #dee2e6;
  --accent: #0d6efd;
  --link: #0a58ca;
  --focus: #fd7e14;
  --shadow: rgba(0, 0, 0, 0.05);
  --msg-mine-bg: #0d6efd;
  ...
}

body {
  background: var(--bg);
  color: var(--text);
}
```

В разметке `bg-white` заменён на свой класс `.surface`, который берёт цвет из переменной —
иначе шапка и карточки оставались бы белыми.

**2. Тёмная тема по настройкам системы**

```css
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --bg: #16181d;
    --surface: #22252b;
    --text: #e6e6e6;
    ...
  }
}
```

`:not([data-theme="light"])` нужен, чтобы ручной выбор светлой темы перебивал системную.

**3. Ручной переключатель** (`js/theme.js`)

- кнопка «Тёмная тема / Светлая тема» в шапке на всех страницах
- тема хранится в `localStorage`; если вручную ничего не выбрано — берётся системная
  через `matchMedia('(prefers-color-scheme: dark)')`, и сайт реагирует, если систему переключить на лету
- тема ставится атрибутом `data-theme` на `<html>`, для этого случая в CSS есть отдельный блок
  `:root[data-theme="dark"]`
- заодно ставится `data-bs-theme` — Bootstrap 5.3 сам перекрашивает свои компоненты
  (поля форм, модалки, таблицы, выпадающие списки)
- скрипт подключён в `<head>` без `defer`, чтобы тема применилась до отрисовки
  и при загрузке тёмной темы не было белой вспышки
- у кнопки `aria-pressed` — скринридер понимает, что это переключатель (продолжение ДЗ2)

**4. Контраст в тёмной теме**

Стандартные outline-кнопки Bootstrap на тёмном фоне сливались,
Lighthouse ругался на кнопку «Написать владельцу» (контраст 3.27 при норме 4.5).
Для `.btn-outline-primary` и `.btn-outline-secondary` в тёмной теме цвета переопределены
через переменные бутстрапа `--bs-btn-color` / `--bs-btn-border-color`.

## Проверка

- Lighthouse Accessibility в светлой и тёмной теме: 100 на поиске, странице объекта, входе и регистрации
- переключение: кнопка в шапке → обновить страницу → тема сохранилась;
  очистить `localStorage` и сменить тему в системе → сайт подстраивается
