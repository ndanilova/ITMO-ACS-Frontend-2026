## Задание

Улучшить доступность ранее сделанного сайта: добавить нужные HTML-атрибуты ко всему контенту
и проверить результат инструментами Firefox DevTools и Google Lighthouse.

## Что сделано

**Навигация и структура**

- ссылка «Перейти к содержимому» в начале каждой страницы — видна только при фокусе с клавиатуры
  (`visually-hidden-focusable`), ведёт на `<main id="content">`
- landmark'и: `nav` с `aria-label="Основная навигация"`, `main`, `aside` для фильтров,
  `section` для результатов поиска
- `aria-current="page"` у активного пункта меню, у кнопки-бургера `aria-label`, `aria-controls`, `aria-expanded`
- порядок заголовков без пропусков: один `h1` на странице, дальше `h2`
  (визуальный размер сохранён классами `h3`, `h5` и т.д.)

**Формы**

- у каждого поля есть `<label for>`; где подпись визуально не нужна — `aria-label` или `visually-hidden`
- цена «от / до» сгруппирована в `fieldset` + `legend`
- `autocomplete` на входе и регистрации (`email`, `current-password`, `new-password`, `given-name`…)
- блоки ошибок с `role="alert"` — скринридер зачитывает ошибку сразу
- счётчик найденных объектов и сумма аренды в модалке обновляются через `aria-live="polite"`

**Модалки**

- `aria-labelledby` на заголовок модалки, у крестика `aria-label="Закрыть"`
- закрываются по Esc, фокус остаётся внутри (это делает Bootstrap)

**Картинки и контент**

- осмысленный `alt` у всех фото (`Фото 2 из 5: Уютная однушка у метро`), у аватара — «Аватар пользователя»
- у стрелок карусели скрытые подписи «Предыдущее фото» / «Следующее фото», иконки с `aria-hidden`
- у кнопок «Подробнее» скрытое уточнение, о каком объекте речь — иначе в списке ссылок
  скринридера шесть одинаковых «Подробнее»
- у кнопок «Одобрить» / «Отклонить» `aria-label` с названием объекта

**Кабинет и сообщения**

- вкладки «Я снимаю / Я сдаю»: `role="tablist"`, `tab`, `tabpanel`, `aria-selected`, `aria-controls`
- у таблицы аренд `caption` (скрытая) и `scope="col"` у заголовков
- список диалогов — `nav` с `aria-label="Диалоги"`, текущий диалог с `aria-current`
- окно переписки `role="log"`, у каждого сообщения скрытая подпись «Вы:» / «Собеседник:»
  (визуально это видно только по цвету и стороне)

**CSS**

- заметная обводка `:focus-visible` (оранжевая, 3px) у ссылок, кнопок и полей
- ссылка «Назад к поиску» на сером фоне не проходила по контрасту — цвет сделан темнее (`#0a58ca`)
