# ЛР1 — Snimu: вёрстка сервиса аренды недвижимости

Вариант 4: сервис для аренды недвижимости. Данилова Анастасия, K3439.

Вёрстка на HTML + CSS + Bootstrap 5, немного JS (фильтры, модалка бронирования, чат).
Бэкенда нет: все данные в разметке — это статичный прототип.

## Запуск

Открыть `index.html` в браузере (двойной клик). Нужен интернет: Bootstrap и фото подгружаются с CDN.

```

## Страницы

| Файл | Что там |
|------|---------|
| `index.html` | Поиск: фильтры (тип, город, цена) + 6 карточек объектов |
| `property.html` | Объект: карусель фото, описание, удобства, условия, модалка «Арендовать» |
| `login.html` | Вход |
| `register.html` | Регистрация |
| `profile.html` | Личный кабинет: вкладки «Я снимаю» / «Я сдаю», модалка «Добавить объект» |
| `messages.html` | Чат с владельцем + история сделок |
